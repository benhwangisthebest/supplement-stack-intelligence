## 5. Build warnings, compared with `a94667e`

- **Known, pre-existing:** `@supabase/supabase-js` reads `process.version`, which the Edge Runtime does not
  support, through `src/lib/supabase/middleware.ts`. It still appears.
- **New, local to this machine:** *"Next.js inferred your workspace root, but it may not be correct."*
  15.5 found a stray `/Users/mac/package-lock.json` in the home directory and chose it as the root over the
  repo's own lockfile. It comes from the machine, not the repo. Silencing it needs `outputFileTracingRoot`
  in `next.config.ts`, which is a source change G did not need, so none was made. It is checked against the
  CI log at landing (unit report).
- No deprecation warning (`next lint`, `legacyBehavior`, AMP, `next/image`) appears in the build or E2E logs.
